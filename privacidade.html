2. Quais dados coletamos

Fizemos um levantamento técnico completo do site e do sistema para listar exatamente o que é coletado — o mapa completo, com origem de cada campo, está em docs/lgpd/data-map.md no repositório do projeto. Em resumo:

2.1 Visitantes do site (público)

  • Hoje, o site não possui formulário de captação de dados (nome/e-mail/telefone) para visitantes — o contato acontece por WhatsApp, telefone ou e-mail, fora do site, por escolha da própria pessoa.
  • Preferência de tema (claro/escuro) e decisão sobre cookies, salvas no seu navegador (localStorage), sem identificar você pessoalmente.
  • Se você enviar uma solicitação de titular pela Central de Privacidade, coletamos nome, e-mail e, se você informar, telefone e CPF/CNPJ — apenas para processar seu pedido.

2.2 Proprietários e inquilinos (contratos de locação geridos pelo corretor)

Para prestar o serviço de administração de locação, o corretor cadastra manualmente, no painel administrativo:

  • Nome completo e CPF/CNPJ;
  • Telefone e e-mail;
  • Endereço;
  • Para proprietários, também dados bancários para repasse de aluguel (banco, agência, conta, chave Pix).

2.3 Corretor (usuário do painel)

  • E-mail e senha de acesso (autenticação);
  • Nome, CRECI, telefone e foto de perfil exibidos publicamente no site.

Não coletamos, hoje: dados de pagamento com cartão, dados de geolocalização, dados de saúde, biometria ou dados sobre crianças e adolescentes.

4. Com quem compartilhamos dados

O inventário completo de fornecedores está em docs/lgpd/third-parties.md. Hoje, os dados podem ser acessados por:

  • Supabase (banco de dados e autenticação) — infraestrutura que hospeda o sistema. Não compartilha dados com terceiros para fins próprios.
  • Google Fonts — carrega apenas as fontes do site; seu navegador faz uma requisição direta ao Google para isso.

Não usamos ferramentas de analytics, pixels de redes sociais, nem vendemos ou alugamos dados pessoais a terceiros para fins de marketing.

Transferência internacional: os servidores do Supabase podem estar localizados fora do Brasil, dependendo da região escolhida na configuração do projeto. A VALIDAR PELO RESPONSÁVEL — ver docs/lgpd/third-parties.md.

Detalhes técnicos completos (nome de cada item salvo, prazo, finalidade) estão em docs/lgpd/cookies.md no repositório do projeto.

6. Segurança dos dados

  • O site é servido inteiramente por HTTPS.
  • O acesso ao painel administrativo exige login (e-mail e senha) e cada sessão expira automaticamente.
  • O banco de dados usa políticas de segurança em nível de linha (Row Level Security) — cada corretor só acessa os próprios registros.
  • Nenhuma senha, chave secreta ou token de acesso fica armazenada no código-fonte do site.

Detalhes da revisão técnica de segurança estão em docs/lgpd/security.md.

7. Retenção e exclusão de dados

Mantemos os dados pessoais pelo tempo necessário para cumprir a finalidade do tratamento e as obrigações legais/contratuais aplicáveis (por exemplo, prazos fiscais e de guarda de contratos de locação). Os prazos específicos de retenção ainda não foram formalmente definidos pelo responsável — ver A DEFINIR PELO RESPONSÁVEL em docs/lgpd/retention.md, que também traz o modelo de consulta SQL para limpeza/anonimização quando esses prazos forem definidos.

Proprietários e inquilinos podem ter seus cadastros corrigidos ou excluídos diretamente pelo corretor no painel, ou mediante solicitação nesta página.
